# polymarket-paper-bot

Учебный paper-trading бот: каждые 5 минут проверяет рынок Polymarket
"BTC up/down 5m" и логирует виртуальную (не реальную) ставку по простому
контртренд-сигналу — если последние 4 свечи BTC-USD (данные Coinbase) подряд
шли в одну сторону, "ставит" против этой серии.

Никаких реальных денег, ключей или логинов — только чтение публичных API
и запись результата в `paper_trades.jsonl`. Цель — накопить статистику и
проверить бэктестом, есть ли в сигнале реальное преимущество или это шум.

## Как это работает

`polymarket_paper_bot.py` — один быстрый проход без ожидания внутри:

1. **Резолв.** Для всех ранее открытых, но ещё не резолвнутых записей, у
   которых окно уже закрылось (>60 сек назад), запрашивает исход и
   дописывает `won`/`pnl`.
2. **Вход.** Если для текущего 5-минутного окна ещё нет записи и сигнал
   есть — открывает виртуальную ставку по текущей цене.

Запускается на GitHub Actions по расписанию (`*/5 * * * *`), сам коммитит
обновлённый `paper_trades.jsonl` обратно в репозиторий.

## Локальный запуск

```bash
pip install -r requirements.txt  # requests
python polymarket_paper_bot.py
```

## Результат проверки (25.09.2026): преимущества нет

Дистанция накоплена и проверена двумя скриптами (данные за 26.08-25.09.2026,
BTC-USD 5m, ставка условно $10, держим до резолва).

**1. Живой лог бота** (`paper_trades.jsonl`, серия n=4, 154 сделки): винрейт
53,9%, P&L -$21, средняя цена входа 0,552 (безубыточно ~55%). 95% интервал
винрейта 46-62% включает и ноль, и плюс - выводов сделать нельзя.

**2. `streak_study.py`** - тот же контртренд для серий 2-8 по свечам Coinbase
(8640 свечей). Выигрыш против серии 51-54%, но это **обманчиво**: оценка
считает исход по Coinbase, а рынок резолвится по Chainlink TWAP.

**3. `entry_study.py`** - честный расчёт: реальные цены входа Polymarket
(CLOB prices-history), итог как резолвнул сам Polymarket и комиссия из
`feeSchedule` рынка (`0.07 * p * (1-p)` от ставки, ~1,75% у цены 0,50).
Окон с сигналом n=3..7: 1939, данные нашлись по всем.

Как перезапустить:

```bash

```

## Честные ограничения

- Сигнал примитивный (простой контртренд по 4 свечам), не оптимизирован.
- Один месяц данных, один рыночный режим.
- Цена входа в `entry_study.py` - последняя сделка/mid на старте окна, а живой
  бот входит по ask и с задержкой cron, поэтому расхождение с логом бота
  ожидаемо.
- Это не финансовый совет и не автоставочник.
